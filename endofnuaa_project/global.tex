\begin{abstract}
本论文面向 Windows 环境下的精密舵机桌面测试任务，围绕 RS422 控制器连接、四路反馈采集、性能指标计算和结果留档设计软件实现。测试现场中，反馈帧以较高频率连续到达，参数填写、图表查看和文件保存的节奏相对较低；二者进入同一界面执行路径时，曲线刷新、状态提示和参数记录容易相互牵制。为处理这一问题，软件采用 Electron、Vue3 和 TypeScript 构建桌面界面与本地调度逻辑，并把界面操作、本地能力访问、任务协调、后台处理、串口通信和测试计算拆分到不同层次。

在该结构下，界面侧只发起受控请求并接收状态事件，通信模块完成两类协议帧的构造、校验、缓存解析和最近反馈样本维护，测试核心在统一运行时接口上执行通信性能测试、控制性能预测试、时域性能测试和频域性能测试。系统输出链路统计、噪声与阶跃参数、位置响应指标、扫频幅相结果和结构化保存文件。实现完成后，本文用自动化测试检查协议解析、测试核心和自动控制逻辑，并在当前联调台架上检查手动收发、高频自动发送和使能检测。检查结果表明，软件已能支撑当前阶段的舵机测试、结果显示和数据留档；24 h 连续运行、完整端到端时延和自动报告生成仍需后续验证。
\end{abstract}
\keywords{精密舵机；测试软件；分层架构；RS422通信；性能测试}

\begin{abstractEn}
This thesis studies a Windows desktop software system for precision servo testing. The system connects to a servo controller through RS422, collects four-channel feedback, computes test indices, and stores test results. During testing, serial feedback frames arrive continuously, while parameter editing, chart inspection, and file operations occur at a lower rate. Placing these operations on one interface path creates interference among refresh timing, state prompts, and parameter records. The implemented software therefore divides the program into user interface, local capability bridge, task coordination, background processing, serial communication, and test-computation layers. Electron, Vue3, and TypeScript are used for the desktop interface and local scheduling logic.

With this structure, the interface sends controlled requests and receives state events. The communication module constructs, verifies, buffers, and parses two protocol frame types, and maintains the latest feedback samples. The test core runs communication performance testing, control performance pretesting, time-domain testing, and frequency-domain testing through a common runtime interface. The software produces link statistics, noise and step-response parameters, position-response indices, swept-sine magnitude and phase results, and structured result files. After implementation, automated tests were used to check protocol parsing, test cores, and automatic control logic. Hardware checks under the current integration condition covered manual transmission, high-frequency automatic transmission, and enable detection. The results indicate that the software can support current-stage servo testing, result display, and data archiving. Continuous 24 h operation, complete end-to-end latency, and automatic report generation still require further verification.
\end{abstractEn}
\keywordsEn{Precision servo; Test software; Layered architecture; RS422 communication; Performance test}
